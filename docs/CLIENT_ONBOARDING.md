# 投顾日报服务 · 客户接入指南（客户版，可转发）

## 一、服务说明

开通后，每个交易日收盘后（约 15:30-16:00）你会收到**专属投顾日报**，内容包含：

- 今日市场速览与估值温度（判断贵不贵）
- 你关注/持有基金的跟踪（净值、收益、回撤、同类排名）
- 今日操作指令（买入 / 卖出 / 持有观望，附原因说明）
- 风险预警与组合诊断

本服务**只提供参考建议，不代操作**，所有买卖由你自己决定。

---

## 二、你需要做什么（约 3 分钟）

只需两步：**注册 Server酱 → 把 Key 发回给我**。

### 第 1 步：微信注册 Server酱

1. 在手机微信里打开链接（或浏览器访问）：**https://sct.ftqq.com**
2. 点击页面右上角 **「登录」**，选择 **「微信登录」**，手机微信确认授权
3. 登录后首次使用需扫码关注微信公众号 **「Server酱」**（接收推送的服务号）

### 第 2 步：绑定微信并获取 SendKey

1. 登录后进入控制台（个人主页），找到 **「微信推送」** 或 **「SendKey」** 区域
2. 点击 **「绑定」** 或 **「获取 SendKey」**，按提示用微信扫码绑定
3. 绑定成功后页面会显示一串 Key，形如：
   ```
   SCT1234567890abcdef...
   ```
   （以 `SCT` 开头的一长串字符，有 "复制" 按钮可直接复制）

### 第 3 步：把 SendKey 发给我

把这串 Key **完整复制（包括 SCT 前缀）**，微信发给我即可。我配置完成后会回复你「已开通」，次日即可收到专属投顾日报。

## 三、常见问题

**Q1：SendKey 是什么？安全吗？**
SendKey 相当于你的"推送投递地址"，只用于向你的微信发送日报消息。请只发送给本服务提供方本人，**不要**发到群里或任何公开场合。

**Q2：服务会不会自动操作我的账户、自动扣款？**
不会。本服务只推送建议文字，**不接触、不连接你的任何资金账户**，无法替你做任何交易。

**Q3：收不到推送怎么办？**
① 确认已关注微信公众号「Server酱」；② 可在 Server酱控制台点「发送测试」自查；③ 仍不行就联系我排查。

**Q4：可以随时退出吗？**
可以。随时告诉我，我会立即移除你的推送配置。

**Q5：我的持仓信息你们会怎么用？**
仅用于生成你的专属日报与风险评估，不会用于其他用途。

## 四、服务提供方操作说明（内部，不转发）

收到客户 SendKey 后：

1. 在 `config.json` 对应客户段（`clients.<ID>`）添加推送覆盖（客户级优先于全局，只推给该客户自己的微信）：
   ```json
   "push": {
     "channel": "serverchan",
     "serverchan_key": "<客户SendKey>"
   }
   ```
2. 更新 GitHub Secret `ADVISOR_CONFIG` 为最新 config.json 内容
3. 回复客户「已开通」，确认次日收到日报
4. 若客户要求退出：删除其 `push` 覆盖或整段客户配置，更新 Secret

> 注：全局 push 段默认推送到服务方本人微信；客户未提供 Key 前，其报告仍推送至全局 Key（便于服务方代看）。
