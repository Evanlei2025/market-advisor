# 数据源审计（D 类维度可行性探索，2026-08-09）

## 说明

- **目的**：score_candidate V3.1 新权重表中部分维度依赖缺失数据源（用户评审指出的缺失关键维度），本审计探明免费数据源可用性，为迭代六接入决策提供依据（A2：只探明不实现）。
- **方法**：本机 Python 3.13 + akshare **1.18.81**（已锁定，未升级）实测；两只覆盖基金：006195 国金量化多因子股票A（股）、675123 西部利得汇逸债券C（债，二级债基）；每个接口均用真实代码拉取并记录列结构、更新频率与单行实测样本；失败如实记录并注明备选。
- **重要前置发现**：akshare 1.18.81 的 fund_hold_structure_em() 与 fund_scale_change_em() 实为**全市场聚合接口**（天天基金 FundDataPortfolio_Interface.aspx，code 参数无效，返回按报告期一行的市场总量），无法支撑单基金维度；单基金数据需走天天基金 F10 底层接口 FundArchivesDatas.aspx（见第 1、5 项）。
- **约束执行情况**：全程只读探测，未修改 market_advisor 下任何 .py 生产代码；探测脚本置于系统临时目录。

## 1. 持有人结构（机构占比/集中度）

- **候选接口**：
  - akshare fund_hold_structure_em()：**不可用**（无参全市场聚合；列：序号/截止日期/基金家数/机构持有比列/个人持有比列/内部持有比列/总份额，字段名含错别字「比列」；实测 code=006195 参数无效，返回市场总量如 2025-12-31 基金家数 24419）
  - 天天基金 F10 底层接口 FundArchivesDatas.aspx?type=cyrjg&code=<代码>&rt=<随机>（需 Referer 头）：**可用**，实测 0.6s 返回
- **列结构**（read_html 解析）：公告日期 / 机构持有比例 / 个人持有比例 / 内部持有比例 / 总份额（亿份）
- **更新频率**：半年报（每年 6/30 与 12/31，约 8 月底与次年 3 月底披露）
- **实测示例**：006195 最近两期：2025-12-31 机构 10.42% / 个人 89.58% / 内部 0.41% / 总份额 10.83 亿份；2025-06-30 机构 21.33%。675123（C 类）2025-12-31 机构 98.72% / 个人 1.28% / 总份额 5.00 亿份 —— 典型机构定制债基，直接支撑「大额赎回风险」评分
- **覆盖范围**：全部开放式基金（A/C 份额各自披露；个别报告期机构占比为「---」表示未达披露阈值或缺失，如 675123 2022 年报）
- **接入建议**：**接入**（预估 0.5 天）。新增一个 F10 数据方法（requests + 固定 Referer + pandas.read_html），随季报披露刷新；报告输出标注报告期（半年滞后）
- **备注**：必须带 Referer 头，否则 404；接口返回 JS 变量包裹的 HTML 片段（content 字段），需先取 content 再 read_html；「---」需按缺失处理（safe_format 兜底「暂缺」）；雪球 fund_individual_basic_info_xq 仅有最新规模，无持有人结构


## 2. 换手率

- **候选接口**：akshare fund_portfolio_change_em(symbol, indicator=累计买入/累计卖出, date=年份)：**可用**，实测 0.8-1.6s/次
- **列结构**：序号 / 股票代码 / 股票名称 / 本期累计买入金额 / 占期初基金资产净值比例 / 季度（坑：卖出表列名同样叫「本期累计买入金额」，akshare 未按 indicator 改名，取值须按 indicator 语义）
- **更新频率**：半年报/年报（每年 2 期；季度标签「2025年2季度」=半年报口径，「2025年4季度」=年报口径）
- **实测示例**：006195 2025 年报期（2025 全年）买入总额 1680618.53 万元、卖出总额 1546545.89 万元；2025 半年报期买入 197217.99 万元、卖出 156820.87 万元。675123（二级债基）2025 年报期股票买入 166215.90 万元、卖出 156271.79 万元
- **覆盖范围**：披露股票买卖金额的基金（股/混/含股债基）；纯债与货币基金无对应披露（date 对应年份无数据时返回空表，读列报 KeyError 序号，需容错）
- **接入建议**：**接入**（预估 0.5 天）。换手率 = min(半年度买入总额, 半年度卖出总额) / 期初净资产（或直接用「占期初基金资产净值比例」列的金额加权口径）；半年度更新一次，滞后标注报告期
- **备注**：date=当年（如 2026）在半年报披露前返回空表且 KeyError，必须 try/except + 空判断；债券基金仅股票部分换手，债券买卖金额不在本接口（纯债基金该项标「不适用」）；可回退季报/半年报公告 PDF 解析（fund_announcement_report_em 拿公告列表，实测可用：基金代码/公告标题/基金名称/公告日期/报告ID）

## 3. 债基久期/杠杆/信用分布（675123 专项）

- **候选接口**：
  - 重仓债券 akshare fund_portfolio_bond_hold_em(symbol, date)：**可用**（仅对含债基金；股票基金报 KeyError 占净值比例）
  - 杠杆率天天基金 F10 资产负债表 FundArchivesDatas.aspx?type=zcfzb&code=<代码>&showtype=1&year=<年份>&rt=<随机>（需 Referer）：**可用**，实测 0.7s
  - 久期/信用评级：结构化免费源**不可得**（重仓债券接口无久期/评级字段；完整持仓与久期评级在季报 PDF 内）
- **列结构**：重仓债券：序号/债券代码/债券名称/占净值比例/持仓市值/季度。资产负债表：科目 x 最近 4 个报告期（资产总计/负债合计/所有者权益合计/卖出回购金融资产款等科目全量）
- **更新频率**：季报（重仓债券 4 季度/年；资产负债表 4 个报告期并列）
- **实测示例**：675123 重仓债券 2025 年 4 季度共 21 行，第一行：25国债13 / 占净值 26.03% / 持仓市值 19114.57 万元。杠杆率 = 资产总计/所有者权益合计：2025-12-31 = 740194641.92/734398874.84 ≈ 1.008 倍（无回购）；2025-06-30 = 226086061.84/206416218.23 ≈ 1.095 倍（卖出回购金融资产款 1000.29 万，杠杆来源为正回购）
- **覆盖范围**：全部基金（股票基金资产负债表亦可得，但债基维度仅对含债基金有意义）
- **接入建议**：重仓债券 + 杠杆率**接入**（预估 1 天，zcfzb 解析 + 杠杆计算 + 重仓债券聚合）；久期/信用分布**降级 config 人工维护**（每季季报披露后人工补录；后续若需自动化再评估季报 PDF 解析）
- **备注**：zcfzb 的 showtype=0 只返回科目名空表（必须 showtype=1）；「---」= 零或未披露；资产负债表为份额自身口径（675123 C 类报告）；可转债/可交换债在重仓债券内（含权益属性，久期近似需剔除）


## 4. A/C 份额列表与费率结构

- **候选接口**：
  - 份额列表 akshare fund_name_em()：**可用**，实测 5.2s 全市场 27479 行
  - 费率 akshare fund_individual_detail_info_xq(symbol)（雪球/蛋卷）：**可用**，实测 0.5s；fund_fee_em(symbol, indicator)：**仅赎回费率可用**（实测申购/管理/托管/销售服务费率均返回空表，接口失效需规避）
- **列结构**：fund_name_em：基金代码/拼音缩写/基金简称/基金类型/拼音全称。fund_individual_detail_info_xq：费用类型（买入规则/卖出规则/其他费用）/条件或名称/费用
- **更新频率**：份额列表每日（新发基金即时入列）；费率随招募书修订低频更新
- **实测示例**：A/C 配对（简称去后缀匹配）：675121 西部利得汇逸债券A + 675123 西部利得汇逸债券C；006195 国金量化多因子股票A + 016858 国金量化多因子股票C。费率对比（同一基金家族）：675121 A 类申购 0.8%/0.6%/0.4%/500 万以上 1000 元封顶、赎回 1.5%/0.5%(7-180 天)/0%、管理 0.6%、托管 0.1%、无销售服务费；675123 C 类申购 0%、赎回 1.5%/0.5%(7-30 天)/0%、管理 0.6%、托管 0.1%、销售服务费 0.1%。006195 A 类管理 1.2%/托管 0.2%；016858 C 类销售服务费 0.4%
- **覆盖范围**：份额列表全覆盖（含 ETF/货币）；雪球费率覆盖非货币基金主流产品，个别新基金/场内品种可能缺
- **接入建议**：**接入**（预估 1 天）。fund_name_em 每日缓存（5s 可接受）用于 A/C 配对与家族识别；detail_info_xq 按需拉取费率；TCO 择优 = 管理费 + 托管费 + 销售服务费 + 申购费摊销 + 按持有期阶梯的赎回费，取费后净值视角择优（延伸现有 fees 缓存逻辑）
- **备注**：雪球申购费为前端费率上限，平台实际折扣更低，择优建议用上限做保守口径并在报告注明；fund_fee_em 大部分 indicator 空返回，勿用；同名家族简称差异（如 675121/675123 拼音全称含 A/C 后缀）可做二次校验；蛋卷接口偶发限流，需超时与重试

## 5. 规模历史序列（point-in-time）

- **候选接口**：
  - akshare fund_scale_change_em()：**不可用**（无参全市场聚合：日期/基金家数/期间申购/期间赎回/期末总份额/期末净资产，为市场总量，code 参数无效）
  - akshare fund_aum_em / fund_aum_hist_em / fund_aum_trend_em：**不可用**（均为基金公司维度：公司排名/历年公司规模排行/行业总规模走势，非单基金）
  - 天天基金 F10 底层接口 FundArchivesDatas.aspx?type=gmbd&code=<代码>&rt=<随机>（需 Referer）：**可用**，实测 0.6s
- **列结构**：日期 / 期间申购（亿份）/ 期间赎回（亿份）/ 期末总份额（亿份）/ 期末净资产（亿元）/ 净资产变动率
- **更新频率**：季度（3/31、6/30、9/30、12/31；6/30 数据实测 8 月初已可得，滞后约 1-2 个月，优于公告披露时点）
- **实测示例**：006195 最近一期 2026-06-30 期末净资产 43.53 亿元（与雪球 fund_individual_basic_info_xq 最新规模 43.53 亿交叉验证一致 ✓），历史 35 行季度序列完整；675123 2026-06-30 期末净资产 50.58 亿元、期间申购 37.89 亿份（单季巨量申购，2025-12-31 净资产仅 5.67 亿，变动率 261.52%），可支撑规模突增/骤降监测
- **覆盖范围**：全部开放式基金（成立满一个报告期）
- **接入建议**：**接入**（预估 0.5-1 天，与持有人结构共用 F10 解析器）。历史行固定不回改，天然 point-in-time，防规模重述（用户评审点）；仅最新行随披露刷新
- **备注**：单位为亿份/亿元；净资产变动率已由源端算好；与雪球最新规模可互为校验；老基金历史序列可达 2010 年代（675123 覆盖 18+ 期）

## 结论

1. **可纳入迭代六接入（4.5 项）**：持有人结构（第 1 项）、换手率（第 2 项）、A/C 份额与费率 TCO 择优（第 4 项）、规模历史序列（第 5 项）四项完整接入；债基专项（第 3 项）中重仓债券与杠杆率部分接入。单基金数据主通道统一走天天基金 F10 底层接口（cyrjg/gmbd/zcfzb 三个 type），一个解析器（取 content + read_html）覆盖 3 个维度，边际成本低。
2. **放弃/降级**：债基久期与信用分布无免费结构化源（重仓债券无久期/评级字段，完整持仓在季报 PDF），降级为 config 人工维护；待后续验证季报 PDF 解析可行性后再评估升级。
3. **必须规避的接口**：fund_hold_structure_em、fund_scale_change_em（市场聚合，错别字字段名，单基金不可用）、fund_aum_*（公司维度）、fund_fee_em 的申购/管理/托管/销售服务费指标（空返回）。
4. **通用坑点**：F10 接口必须带 Referer 头否则 404；返回体为 JS 变量包裹的 HTML 片段；「---」= 缺失/零值，须经 safe_format 兜底「暂缺」；所有报告期类数据均有披露滞后（半年报数据 8 月底/次年 3 月底，季报 1-2 个月），接入时须随报告标注报告期与滞后提示；债券基金换手率仅覆盖股票部分。
5. **交叉校验可用**：规模历史（F10 gmbd）与雪球最新规模可互验（006195 均为 43.53 亿 ✓）；A/C 配对可用 fund_name_em 简称 + 拼音全称双重校验。
